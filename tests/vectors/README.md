# Protocol vectors

The draft-02 conformance vector used by this repository is copied from the
Ed25519 example in Appendix E.2.1 of
[`draft-meunier-webbotauth-httpsig-protocol-02`](https://www.ietf.org/archive/id/draft-meunier-webbotauth-httpsig-protocol-02.html), published 18 August 2026. The
public key is the RFC 9421 Appendix B.1.4 demonstration key, whose RFC 7638
thumbprint is
`poqkLGiymh_W0uP6PZFw-dvez3QJT5SolqXBCW38r0U`.

The adopted
[`draft-ietf-webbotauth-httpsig-protocol-00`](https://www.ietf.org/archive/id/draft-ietf-webbotauth-httpsig-protocol-00.html)
contains the same example unchanged. The original source name remains here as
immutable fixture provenance.

The request headers, signature parameters, nonce, and signature are copied as
wire values from the draft. They are immutable test input; expected signatures
are not generated by the `web-bot-auth` dependency at test time. The vector is
used only for cryptographic conformance; production rejects this demonstration
key unless the fixture-only test-key switch is enabled.

The IETF Internet-Draft text is available under the IETF Trust Legal Provisions
for IETF Documents. This repository includes only the small values needed to
exercise the protocol, not a copy of the draft text.
